# 🔏 Kerning Stego

**Kerning Stego** — современное высокотехнологичное веб-приложение для скрытой передачи сообщений методом **Кёрнинга** (типографической стеганографии).

Система позволяет встраивать секретные сообщения в открытый текст посредством незаметных для человеческого глаза микроизменений межбуквенных интервалов и невидимых Unicode-маркеров нулевой ширины, сохраняя полную читаемость и естественный вид исходного текста.

---

## ✨ Ключевые возможности

- 🔒 **Полная невидимость**: Внешне текст выглядит абсолютно обычно и не вызывает подозрений.
- ⚡ **Мгновенное кодирование и декодирование**: 100% клиентская обработка данных (Client-Side), информация никуда не передается по сети.
- 🛡️ **Контроль целостности CRC16**: Встроенная 16-битная контрольная сумма CCITT исключает повреждения и ложные срабатывания.
- 📊 **Инспектор кёрнинга**: Интерактивный визуализатор, подсвечивающий каждый внедрённый бит (`0` и `1`) и дельту расстояния (`letter-spacing`).
- 💾 **Экспорт в HTML и TXT**:
  - Экспорт в автономный **HTML**-документ с точным сохранением CSS `letter-spacing` межбуквенных интервалов.
  - Экспорт в **TXT**-файл со стеганографическими Unicode-маркерами.
- 📋 **Удобное копирование**: Поддержка передачи скрытых сообщений через буфер обмена в популярные мессенджеры (Telegram, WhatsApp и др.).
- 🎨 **Premium Dark UI**: Выдержанная минималистичная эстетика кибербезопасности, Glassmorphism, мягкие зелёные акценты (`#8BF58D`), сгенерированные 3D-ассеты и плавная анимация на Framer Motion.

## 🚀 Быстрый старт

### Требования
- **Node.js** v18+ 
- **npm** или **yarn** / **pnpm**

### Установка зависимостей
```bash
git clone https://github.com/ngvdmr26/Kerning-Stego.git
cd Kerning-Stego
npm install
```

### Запуск в режиме разработки
```bash
npm run dev
```
Приложение откроется по адресу `http://localhost:5173/`.

### Сборка для production
```bash
npm run build
```
Готовые оптимизированные статические файлы будут сохранены в директории `dist/`.

## 🔬 Принцип работы метода Кёрнинга

1. **Бинарная сериализация**: Секретное сообщение преобразуется в бинарный поток UTF-8.
2. **Формирование пакета**:
   - `Magic Header` (16 бит: `0x4B53` — сигнатура «KS»)
   - `Payload Length` (16 бит: длина полезной нагрузки в байтах)
   - `CRC16 Checksum` (16 бит: контрольная сумма данных)
   - `Payload Bits` ($N \times 8$ бит полезных данных)
3. **Модуляция интервалов**:
   - Бит `1`: расширенный межбуквенный интервал (+0.12em / `U+200B Zero Width Space`).
   - Бит `0`: стандартный/суженный интервал (-0.015em / `U+200C Zero Width Non-Joiner`).
4. **Слепое извлечение**: Декодер автоматически обнаруживает маркеры, валидирует заголовок и CRC16, восстанавливая исходный текст без необходимости передачи исходного текста-обёртки.
